# Building community agents with NanoClaw

This course introduces:

1. A basic developer setup.
2. The basic parts of an agent [harness](../glossary.md#harness): the model, the tools, and the data.
3. A basic integration that uses Notion to store data.

## Important notes

1. This course uses our own copy of NanoClaw. It is a [fork](../glossary.md#fork): a copy of a project that you can change without changing the original. We changed it with NanoClaw's own skills, so that it works with Telegram and Codex. Our changes are saved in the [aith-nanoclaw-codex-telegram](https://github.com/aijutsu/aith-nanoclaw-codex-telegram) project on GitHub.
